Gülüm, yaşatdın məni,
Gecənin o tayında.

Göyə ucaltdın məni
Gecənin o tayında.

Odlu bilməcələr var,
Dadlı düşüncələr var.

Gündüzlü gecələr var
Gecənin o tayında.

Gecənin o tayında
Könül arzumu gördüm.

Bəxt ulduzumu gördüm
Gecənin o tayında.

Bu dünyadan nə anlar
Eşqə tutulmayanlar?!

Yaşar əbədi anlar
Gecənin o tayında.

Boşluğa atdın məni,
Dərdə uğratdın məni.

Zülmətə qatdın məni
Gecənin o tayında.
