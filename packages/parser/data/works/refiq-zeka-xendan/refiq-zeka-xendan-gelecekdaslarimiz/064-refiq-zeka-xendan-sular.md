Sular var, arası buz bağlayıbdır,
Sular var, yarası duz bağlayıbdır.

Sular var yerlərin gizli qatında,
Sular var göylərin yeddi qatında.

Sular var, nəfəsi alınmış sular,
Dərman qablarına salınmış sular.

İçilməz sular var bu yer üzündə,
Keçilməz sular var bu yer üzündə.

Sular var yağışdır, sular var, dolu,
Sular var işıqlı arzular dolu!

Sular var güllərin üstə saxlanar,
Sular var altında yurd bataqlanar.

Sular var damcıdır, sular var bulaq,
Sular var dalğadır, sular var irmaq!

Sular var dağlardan axıb sellənər,
Sular var dərəyə dolub, göllənər.

Sular var titrəyər fəvvarələrdə,
Sular var kükrəyər şəlalələrdə.

Sular var göz yaşı, sular var səfa,
Sular var zəhərli, sular var şəfa.

Sular var aranı sərhəd eyləyər,
Qardaşı qardaşa həsrət eyləyər.

Sular var çay olur, sular var dəniz,
Dənizlər arzudur, arzular – dəniz.

Sular var birlikdə bir okeandır,
Ruhunu okean eşqinə yandır!
